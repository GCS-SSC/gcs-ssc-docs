# Autres noms de promoteur

Autres noms enregistre les noms alternatifs d un promoteur. Ils aident les utilisateurs a trouver et interpreter les organisations qui utilisent plusieurs noms ou qui ont change de nom.

## Champs

| Champ | Regle |
| --- | --- |
| Nom anglais | Nom alternatif anglais obligatoire. |
| Nom francais | Nom alternatif francais obligatoire. |
| Description | Contexte optionnel: ancien nom, nom commercial, acronyme ou ancien nom legal. |

## Regles metier

| Regle | Comportement |
| --- | --- |
| Les noms doivent etre utiles | N ajoutez pas de ponctuation seule, de doublons ou de mots-cles temporaires. |
| Les noms historiques devraient rester disponibles | Conservez les anciens noms lorsqu ils expliquent des ententes ou documents historiques. |
| Les valeurs bilingues doivent etre appariees | Si un seul nom existe, repetez le nom accepte dans les deux champs. |
| Les suppressions sont logiques | Un nom retire est masque des listes actives sans effacer le contexte. |

## Conseils

Ajoutez les autres noms avant que les utilisateurs commencent a rechercher le promoteur lors de la creation d entente. Cela reduit les doublons de profils.
